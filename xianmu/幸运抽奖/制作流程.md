1.2
指定普通文本文件(*.txt)为名单，以行为单位读取学员名字。
随机抽取的过程在终端动态展现出来
1.3 
支持一次抽取 N 个随机幸运儿
支持逐次抽取幸运儿，且不重复抽取

4.问题
1.输出出现中文乱码
    例子：
��亚龙血武姬�
最终中奖者是: ��亚龙血武姬�
    原因：
程序自己把 UTF-8 中文名截断了，导致输出乱码。#define MAX_NAME_LEN 20 太小。
英雄名单是 UTF-8 编码，一个汉字占 3 字节。而 fgets(names[count], MAX_NAME_LEN, fp) 最多只读 19 字节（20 减结尾的 \0），19 字节只能装下 6 个完整汉字 + 1 个字节——第 7 个汉字被拦腰截断，只剩半个字节，终端解不出来就显示成 �。
    解决方法：
#define MAX_NAME_LEN 20    →    #define MAX_NAME_LEN 50
将#define MAX_NAME_LEN 变大，即可解决乱码问题。

2.闪屏时间长短不好控制
    例子：
例如，我们希望闪屏时间是从 500000 微秒，每次闪屏间隔 *2，闪屏时间大于 2000000微秒。
但是，实际运行时，只闪屏2次，其他时间都是等待。
    原因：
将delay设置成循环条件，难以控制每次闪屏的时间。
    解决方法：
设置闪屏次数，将delay在循环中每次等于自己的1.25倍。（或者用数学函数将时间递减的更加丝滑）。

5.AI优化
1.names[count][strcspn(names[count], "\r\n")] = '\0';
去除字符串 names[count] 末尾的换行符（\n）或回车符（\r），并将它们替换为字符串结束符 '\0'。

    为什么要同时检查 \r 和 \n？
因为不同的操作系统换行符不同：
系统	            换行符
Linux / macOS	    \n（换行）
Windows	            \r\n（回车 + 换行）
如果你在 Windows 上创建了 heroes.txt 文件，然后放到 WSL（Linux）中读取，文件每行末尾是 \r\n。只用 strcspn(names[count], "\n") 只能去掉 \n，会留下 \r，导致显示时出现额外的空白或覆盖问题。
而用 "\r\n" 作为分隔符，可以同时处理两种换行格式，提高代码的兼容性。

    这行代码的好处
兼容性好：无论文件是 Linux 格式（\n）还是 Windows 格式（\r\n），都能正确去掉末尾的换行符。
安全：如果字符串中没有 \r 或 \n，strcspn 返回长度，赋值给 [长度] 本身就是 '\0'，不会越界。
简洁：比手动循环查找更优雅


2.fprintf(stderr, "\r%s\033[K", names[idx]);
\033[K 是 ANSI 转义序列，作用是清除从光标到行尾的所有内容。
这样：
名字会被正确显示
之前循环留下的长名字残字会被自动清掉
光标紧跟在名字后面，不会再跑到老远的地方
